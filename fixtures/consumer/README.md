# Consumer fixture

Minimal external-consumer simulation for **manual** Savepoints Lite verification. Not a production adoption path.

1. `npm ci` (registry install of pinned `@multipliers-dev/savepoints-lite@1.0.0`).
2. Open agent sessions with this directory as context.
3. Follow [`../../skills/savepoints/verification.md`](../../skills/savepoints/verification.md).

Activation files are copied from [`../../templates/consumer/`](../../templates/consumer/). Hub dogfooding on the package repository root is a **separate required** acceptance path — see [`../../docs/adoption-verification-record.md`](../../docs/adoption-verification-record.md).
